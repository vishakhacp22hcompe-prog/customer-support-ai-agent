# Customer Support AI Agent

A grounded customer-support AI agent that answers knowledge-base questions, looks up orders, supports multi-turn conversations, and avoids guessing unavailable information.

## Features

- Knowledge-base question answering with citations
- Order lookup
- Multi-turn order conversations
- Current-policy priority over legacy information
- Damaged/wrong-item handling
- Protection of private order information
- No invented delivery estimates
- Local language model
- Automated pytest evaluation suite

## Demo

The 2–4 minute demo shows:

1. Knowledge-base question with citations
2. Order lookup
3. Multi-turn conversation
4. Correct refusal to guess / human-help recommendation
